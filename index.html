☁ Sincronización entre celulares

Para compartir la misma información con tus compañeros, esta página necesita una base de datos online. Una opción es Supabase (plan gratuito). Configúrala una sola vez y pega la misma URL y clave pública en cada celular.

  1. Crea un proyecto en supabase.com.
  2. En SQL Editor, ejecuta el SQL que aparece abajo.
  3. En Project Settings → API copia la Project URL y la clave anon/public.
  4. Pega esos datos aquí y pulsa Conectar. Todos los compañeros deben configurar los mismos datos.

SQL para crear la tabla

create table if not exists public.squid_expenses (
  id text primary key,
  category text not null check (category in ('dalgona','sal','bebidas')),
  item text not null,
  quantity numeric not null default 1,
  unit text not null default 'unidad',
  total_cost numeric not null default 0,
  responsible text default '',
  notes text default '',
  created_at timestamptz not null default now()
);
alter table public.squid_expenses enable row level security;
create policy "shared read" on public.squid_expenses for select to anon using (true);
create policy "shared insert" on public.squid_expenses for insert to anon with check (true);
create policy "shared update" on public.squid_expenses for update to anon using (true) with check (true);
create policy "shared delete" on public.squid_expenses for delete to anon using (true);
grant select, insert, update, delete on public.squid_expenses to anon;

create table if not exists public.squid_plans (
  category text primary key check (category in ('dalgona','sal','bebidas')),
  quantity numeric not null default 20,
  price numeric not null default 2000,
  updated_at timestamptz not null default now()
);
alter table public.squid_plans enable row level security;
create policy "shared plans read" on public.squid_plans for select to anon using (true);
create policy "shared plans insert" on public.squid_plans for insert to anon with check (true);
create policy "shared plans update" on public.squid_plans for update to anon using (true) with check (true);
grant select, insert, update on public.squid_plans to anon;
insert into public.squid_plans (category, quantity, price)
values ('dalgona',20,2000), ('sal',20,2000), ('bebidas',20,2000)
on conflict (category) do nothing;

Aviso: estas reglas permiten que cualquiera con la URL y la clave pública pueda editar o borrar los datos. Úsenlo solo para este proyecto temporal y no guarden información privada. No compartas la clave service_role.
